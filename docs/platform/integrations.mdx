## Choose your path

| Scenario | Recommended approach |
| :-- | :-- |
| Building a new application? | Start with the SDK quickstart, then add retrieval and memory to the request lifecycle. |
| Already using an agent framework? | Check whether a maintained Negentro adapter exists for your framework and version before relying on it for production. |
| Working across multiple languages? | Use the REST API where it provides the functionality and operational controls your application needs. |
| Connecting enterprise data? | Start by defining source permissions, synchronization behavior, deletion propagation, and data ownership. |

## Integration best practices

- Keep API credentials on trusted server-side systems.
- Use least-privilege access and clear ownership boundaries.
- Define timeouts, retries, and idempotency behavior where applicable.
- Monitor connector failures and synchronization lag.
- Test update and deletion behavior across integrated systems.
- Pin and validate dependency versions before production rollout.

## Ready to connect?

Start with the interface that best fits your application, then expand to frameworks and data sources as your requirements grow.
