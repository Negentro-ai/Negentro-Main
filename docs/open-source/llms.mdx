## Local Ollama Configuration

Run 100% private, on-premise memory pipelines without sending tokens to third-party APIs:

```python python_ollama.py
from negentro import Memory

config = {
    "llm": {
        "provider": "ollama",
        "config": {
            "model": "llama3.3:latest",
            "base_url": "http://localhost:11434"
        }
    }
}

m = Memory.from_config(config)
```
