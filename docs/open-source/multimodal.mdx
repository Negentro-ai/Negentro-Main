## Ingesting Image Memories

```python multimodal_example.py
# Store an image with automatic vision fact extraction
m.add(
    "Architecture diagram showing Kubernetes cluster with 3 worker nodes and Istio service mesh.",
    user_id="usr_9918",
    metadata={
        "type": "image",
        "image_url": "https://storage.internal/diagrams/k8s_mesh.png"
    }
)

# Natural language query retrieves image memory
results = m.search("How many worker nodes are in our Kubernetes cluster?", user_id="usr_9918")
```
