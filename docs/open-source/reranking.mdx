## Tuning Retrieval Parameters

```python rerank_config.py
results = m.search(
    query="User preferences for deployment target",
    user_id="usr_9918",
    alpha=0.7,             # 0.7 Vector weight / 0.3 BM25 text weight
    min_score=0.25,         # Rejects low-confidence matches
    recency_decay_days=30  # Half-life for temporal fading
)
```
