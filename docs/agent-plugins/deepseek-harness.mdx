## BYOK Configuration

Add your encrypted DeepSeek API key via the platform BYOK management endpoint:

```bash Terminal
curl -X POST https://api.negentro.cloud/api/v1/byok/keys \
  -H "Authorization: Bearer $NEGENTRO_API_KEY" \
  -d '{"vendor": "deepseek", "api_key": "sk-deepseek-..."}'
```
