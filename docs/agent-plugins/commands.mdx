| COMMAND | ARGS | DESCRIPTION |
| :-- | :-- | :-- |
| /memory:search | <query> | Query past session memories with semantic ranking. |
| /memory:status | none | Print active plugin version, user scope, and memory count. |
| /memory:remember | <text> | Force-capture an explicit memory block. |
| /memory:forget | <id> | Soft-delete a specific memory from retrieval. |
| /memory:pause | none | Temporarily pause automatic context recording. |
| /memory:resume | none | Resume automatic background context capture. |
