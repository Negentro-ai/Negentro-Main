Install plugins via the Negentro CLI or configure your IDE's Model Context Protocol client.

## Via Negentro CLI

```bash Terminal
npm install -g @piyapi/cli
negentro plugin install <plugin-name>
```

## Via npx stdio (Cursor / Claude Desktop)

```bash Terminal
npx -y @piyapi/mcp-server
```
