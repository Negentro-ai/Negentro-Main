## What you can do

## Commands

## Search tool

Use the search tool to query prior sessions and retrieve context matched by relevance and scope.

## Sidekick agent

The sidekick agent handles isolated investigation or implementation work in a separate context, then returns findings to the main agent without polluting its working memory.

| COMMAND | WHAT IT DOES |
| :-- | :-- |
| /memory:search | Search memories from earlier sessions. |
| /memory:status | Check current memory/configuration state. |
| /memory:forget | Delete or forget selected memories. |
| /memory:pause | Pause automatic memory capture. |
| /memory:resume | Resume automatic memory capture. |
| /memory:remember | Explicitly capture something important. |

## How it works

## Memory scoping

Memory is scoped between shared project context and personal context, with relevant overlap surfaced during retrieval.

## Search scope

Example: setting scope to dir narrows retrieval to memories captured within the current working directory only.

| SCOPE | WHAT YOU GET |
| :-- | :-- |
| repo | Project memory. |
| dir | Directory-specific context. |
| user | Personal memory. |
| session | Current session context. |

## Settings

| SETTING | DEFAULT | WHAT IT CONTROLS |
| :-- | :-- | :-- |
| api_key | none | Authenticates requests to Negentro. |
| user_id | none | Identifies the memory owner. |
| top_k | 5 | Number of memories returned per search. |
| max_content_chars | 4000 | Max characters captured per memory. |
| search_scope | repo | Default scope used for retrieval. |
| telemetry | true | Enables anonymous usage telemetry. |

## Upgrading

Before upgrading to a new plugin version, walk through the checklist below to avoid breaking existing configuration or memory behavior.

## Troubleshooting

| PROBLEM | FIX |
| :-- | :-- |
| Missing API key | Configure the Negentro API key and restart the plugin. |
| Unauthorized | Verify the API key and account permissions. |
| No memory after session | Check that memory capture is enabled and that the plugin completed its session flush. |
| Plugin won't start | Verify the supported agent version and plugin installation. |
| Search returns nothing | Check the active search scope and confirm memories exist for that scope. |
