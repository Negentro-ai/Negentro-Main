Enterprise-grade bitemporal storage substrate and dense vector indexes backing Negentro / PiAPI.

The core storage layer relies on PostgreSQL with the pgvector extension for high-performance HNSW indexing on 1536-dimensional embeddings. Bitemporal validity tracks real-world time ( valid_at ) separately from system record time ( system_at ), ensuring strict point-in-time state reconstruction.
