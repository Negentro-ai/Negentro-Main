Multi-signal hybrid retrieval engine combining dense vector search and BM25 trigram full-text search.

Combines dense vector similarity (pgvector HNSW indexes) and BM25 full-text search fused using Reciprocal Rank Fusion ( RRF_K=30 ) and evaluated across 11 signals with the UnifiedScorer.
