# Getting Started

To get started with Negentro, follow these simple steps.

## 1. Sign Up
Go to your Negentro dashboard and create an account.

## 2. API Keys
Navigate to your settings and generate an API key.

## 3. Make your first request
You are now ready to make your first AI request!
