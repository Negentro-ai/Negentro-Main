## LangChain Adapter Integration

```python Python — LangChain Adapter
from piyapi_langchain import PiyAPIMemoryRetriever

retriever = PiyAPIMemoryRetriever(
    api_key="sk_live_your_api_key_here",
    top_k=5
)

# Retrieve relevant documents as LangChain Document objects
docs = retriever.get_relevant_documents("user database preferences")
for doc in docs:
    print(doc.page_content, doc.metadata)
```
