## Extracting Unstructured Session Insights

```bash POST /api/v1/sessions/mine
curl -X POST https://api.piyapi.cloud/api/v1/sessions/mine \
  -H "Authorization: Bearer sk_live_prod_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      { "role": "user", "content": "I am analyzing quantum error correction benchmarks on neutral atom hardware." },
      { "role": "assistant", "content": "Neutral atom systems typically leverage Rydberg blockade gates." }
    ]
  }'
```
