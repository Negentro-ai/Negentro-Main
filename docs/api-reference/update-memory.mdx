Modify content, tags, or bitemporal validity of an existing memory record, generating a new revision version.

```bash PATCH /api/v1/memories/:id
curl -X PATCH https://api.piyapi.cloud/api/v1/memories/8a1b2c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \

    "content": "Updated compliance audit report status: Approved.",
```
