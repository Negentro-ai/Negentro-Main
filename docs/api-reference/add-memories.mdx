`POST /api/v1/memories`

```bash POST /api/v1/memories
curl -X POST https://api.piyapi.cloud/api/v1/memories \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Client requested SOC2 Type II compliance audit report for Q3 2026.",
    "tags": ["compliance", "soc2", "audit"],
    "metadata": { "client_id": "cli_8812", "urgency": "high" },
    "valid_at": "2026-08-01T00:00:00.000Z"
  }'
```
