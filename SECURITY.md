# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| Latest SDK | ✅ |
| Older SDK | Report if critical |

## Reporting a Vulnerability

**DO NOT open a public GitHub issue for security vulnerabilities.**

Email: `piyapi.cloud@gmail.com`  
Response time: 48 hours  
Disclosure: 90-day coordinated disclosure policy

We credit all valid reporters in our security advisories.
